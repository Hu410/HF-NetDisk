## 已知限制

- 单密码模型适用于个人使用，不提供多用户权限和审计主体隔离。
- 目录数据直接来自 Hugging Face API；超大仓库的列表延迟受上游影响。
- Cloudflare 告警需要在账号控制台按运维手册创建，仓库配置不能代替账号级通知。
- Worker 回滚不等于存储数据回滚。
